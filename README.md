# JAZZ BEAUTY PARLOUR & BRIDAL HUB
> *Where Beauty Meets Artistry.*

A luxury editorial beauty and bridal website designed for **Jazz Beauty Parlour & Bridal Hub** (Radio Junction, Thazhava, Karunagappally, Kollam, Kerala). Inspired by high-end fashion magazines, modern haute couture aesthetics, and bespoke bridal studios.

---

## ✨ Features

- **Cinematic Parallax Hero:** Full-bleed silent background video with editorial overlay gradients, fluid typography, and live booking CTAs.
- **Bespoke Services Showcase:** Comprehensive modal previews for:
  - 👑 **Bridal Makeover** (Royal wedding styling & jewelry draping)
  - 💇 **Hair Artistry** (Precision cuts, balayage, keratin & bridal updos)
  - 🌿 **Skin Rituals** (Hydra-facials, gold leaf firming & bridal glow)
  - 💄 **Makeup Artistry** (HD & airbrush reception glam)
  - 🧵 **Precision Threading** (Eyebrow shaping, arch mapping & facial hair removal)
  - 🦚 **Mehndi Art** (Intricate bridal peacocks & organic henna)
  - 🕯️ **Beauty & Spa** (Paraffin manicures, body wraps & rejuvenation)
- **Interactive Transformations:** Dual-handled touch/mouse drag-to-reveal before & after comparison slider.
- **Editorial Bridal Lookbook:** Asymmetric high-fashion masonry gallery with smooth hover reveals.
- **Direct WhatsApp Concierge:** Instant appointment booking with auto-formatted service, date, and client details sent straight to `+91 99617 51627`.
- **Strict Brand Design System:**
  - **Headings:** Cormorant Garamond (Editorial Serif)
  - **Body:** DM Sans (Clean Modern Sans)
  - **Color Palette:** Warm Ivory (`#F8F3ED`), Deep Plum (`#482638`), Rosewood (`#A66D78`), Champagne Gold (`#C6A477`), Espresso (`#29201F`)
  - **Photography:** Custom AI-generated bridal and luxury still-life photography adhering to strict face-free / still-life guidelines.
- **100% Responsive:** Optimized for mobile phones (320px+), tablets, laptops, and ultra-wide desktop monitors.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [npm](https://www.npmjs.com/)

### Installation

```bash
# Clone the repository
git clone https://github.com/adithyanp2005gt-dotcom/jazz-beauty-parlour.git

# Navigate to the project directory
cd jazz-beauty-parlour

# Install dependencies
npm install

# Start development server
npm run dev
```

The application will be running at `http://localhost:5173/`.

### Production Build

```bash
npm run build
npm run preview
```
